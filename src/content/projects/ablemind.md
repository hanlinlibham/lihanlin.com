同一 Kernel 装配出 Web、CLI、VS Code 与微信多个薄终端，会话与工作区语义不变。

## 工作前提可见

规则、记忆开关、技能、数据源和当前状态常驻在工作台里。影响 Agent 行为的东西放在用户看得见、能纠正的地方。

## 失败语义诚实

区分「正在运行」「工具出问题」「部分完成」「失败」。多任务共享额度提前披露，缺口如实标出，已有结果保留。

## 断线不重来

长任务断线后用连接状态灯和原任务订阅恢复，不重发用户命令；UI 回放、执行恢复与任务状态保护分开处理。

完整架构见 [/ablemind/](/ablemind/)。
